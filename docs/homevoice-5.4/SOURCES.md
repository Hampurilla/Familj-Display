# Källor

Kontrollerade 2026-09-12. Primära källor för externa funktioner. Testresultat
för vår egen kod finns separat.

* Tailscale Serve: https://tailscale.com/docs/features/tailscale-serve
* Serve CLI och bestående --bg: https://tailscale.com/docs/reference/tailscale-cli/serve
* iOS VPN On Demand (Always på Wi-Fi och Cellular): https://tailscale.com/docs/features/client/ios-vpn-on-demand
* iOS installation: https://tailscale.com/docs/install/ios
* Apple hemskärmsapp: https://support.apple.com/en-kw/guide/iphone/iphea86e5236/ios
* eSpeak NG och röstens egenskaper: https://github.com/espeak-ng/espeak-ng
* Svenska sv: https://github.com/espeak-ng/espeak-ng/blob/master/docs/languages.md
* CLI stdin/WAV: https://github.com/espeak-ng/espeak-ng/blob/master/src/espeak-ng.1.ronn
* WebAudio user gesture: https://developer.chrome.com/blog/web-audio-autoplay
* Pi ljudutgång: https://www.raspberrypi.com/documentation/computers/configuration.html
* AUX-nivå: https://www.raspberrypi.com/documentation/computers/getting-started.html

Programmen installeras separat från OS/Tailscale. Ingen eSpeak-binär eller röstmodell
eller typsnittsfil distribueras i ZIP-paketet.
